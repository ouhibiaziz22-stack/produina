# AZIX Electric Storm

Build a website for brand AZIX with a black and white background and animated electric thunder and lightning. The site has just two main components:
1. Clothes: apparel showcase (oversized hoodies, heavy cotton tees, cargo pants) with product cards, size selection, high-contrast hover effects, and cart/pre-order functionality.
2. BAC 2K27: dedicated capsule collection for the Class of 2027 promo gear with an electric BAC 2K27 badge, countdown, and pre-order/bulk inquiry options.
